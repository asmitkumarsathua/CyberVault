# CyberVault

CyberVault is a cybersecurity learning platform landing page built using HTML, CSS, and JavaScript.

## 🌐 Live Website

https://asmitkumarsathua.github.io/CyberVault/

## 📌 About

CyberVault is a frontend project designed to provide a clean and modern interface for learning cybersecurity.

The website includes:

- Cybersecurity learning resources
- Course sections
- Feature highlights
- About section
- User signup form
- Responsive navigation
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages


## 🎓 Learning Project

CyberVault is a learning project created to practice web development, Git, GitHub, and deployment.

AI was used as a development and learning assistant to help with understanding concepts, writing and improving code, debugging, and exploring ideas.

This project is not intended as a production cybersecurity platform.
